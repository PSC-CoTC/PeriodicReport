# PeriodicReport

The periodic report is still in draft form; the report is the `index.html` file, which can be downloaded from this folder.

`index.html` is generated from `index.qmd`, a quarto document. `index.qmd` relies in part on sensitive data that is stored external to this repository; as such, the `.qmd` document may not compile on your computer without additional file access.



For questions or suggestions, contact Collin Edwards, Diego Holgren, or John Brady from the Coho Technical Committee.
